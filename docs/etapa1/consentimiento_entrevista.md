# Consentimiento informado para entrevista

**Proyecto:** Sistema generativo interactivo de portadas para libros infantiles
**Curso:** Planificación y Toma de Decisiones en IA — UTEC · **Profesora:** Dra. Aurea Soriano-Vargas
**Equipo:** Andrea Coa, Nayeli Guzman, Maria Surco, Bihonda Epiquien, Jimena Gurbillon

Te invitamos a una entrevista de 20 a 30 minutos sobre cómo se crean o eligen portadas de cuentos infantiles. Tus respuestas nos ayudarán a diseñar una herramienta académica; no es una evaluación de tu trabajo.

- **Participación voluntaria:** puedes no responder alguna pregunta o terminar la entrevista cuando quieras, sin dar explicaciones.
- **Grabación:** solo si lo autorizas, grabaremos el audio para transcribirlo. El audio se borra al terminar el curso.
- **Confidencialidad:** en el informe no aparecerá tu nombre; usaremos un código (P1, P2...) y citas sin datos que te identifiquen.
- **Dibujos o bocetos:** si nos compartes un boceto, solo lo usaremos para probar el sistema dentro del proyecto, sin publicarlo, salvo que marques lo contrario abajo.
- **Contacto:** para retirar tu participación o tus datos, escribe a cualquier integrante del equipo.

- [ ] Autorizo usar mi boceto para probar el sistema (sin publicarlo).
