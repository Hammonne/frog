# Cuestionario de usabilidad (SUS)

Marca de 1 (totalmente en desacuerdo) a 5 (totalmente de acuerdo). Se refiere a la herramienta que acabas de usar.

| # | Afirmación | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | Creo que me gustaría usar esta herramienta con frecuencia. | | | | | |
| 2 | Encontré la herramienta innecesariamente compleja. | | | | | |
| 3 | Pensé que la herramienta era fácil de usar. | | | | | |
| 4 | Creo que necesitaría ayuda de una persona con conocimientos técnicos para usarla. | | | | | |
| 5 | Encontré que las funciones de la herramienta estaban bien integradas. | | | | | |
| 6 | Pensé que había demasiada inconsistencia en la herramienta. | | | | | |
| 7 | Imagino que la mayoría de las personas aprendería a usarla muy rápido. | | | | | |
| 8 | Encontré la herramienta muy incómoda de usar. | | | | | |
| 9 | Me sentí muy seguro/a usando la herramienta. | | | | | |
| 10 | Necesité aprender muchas cosas antes de poder usarla. | | | | | |

**Cálculo:** preguntas impares (1, 3, 5, 7, 9): respuesta − 1. Preguntas pares (2, 4, 6, 8, 10): 5 − respuesta. Se suma todo y se multiplica por 2,5. Resultado de 0 a 100; 68 es el promedio de referencia.
